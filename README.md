# Прототип Pixel Tools

Интерактивный прототип решения тестового задания: сводка проекта и ИИ-помощник на одном экране. Каждый показатель передаёт помощнику вопрос с контекстом; ответы и следующие действия подготовлены для демонстрационного проекта.

- Аналитика: видимость, запросы, сравнение выдачи, конкуренты и технические ошибки.
- Разборы сохраняются в общем диалоге; план исправления можно согласовать или отклонить.
- Все данные вымышлены. Работа ИИ имитируется в браузере, внешние LLM и API не подключены.

Для локального просмотра откройте `index.html`. Установка зависимостей и сборка не требуются.

Публикация: GitHub Pages из корня ветки `main`. Изменения сайта публикуются после push в `main`.
