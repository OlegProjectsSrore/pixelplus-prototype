# Прототип Pixel Tools

Интерактивный прототип решения тестового задания: сводка проекта и ИИ-помощник на одном экране. Каждый показатель передаёт помощнику вопрос с контекстом; ответы и следующие действия подготовлены для демонстрационного проекта.

- Сводка: органический трафик, заявки, небрендовая видимость, спрос на бренд, присутствие в ИИ, проблемы важных страниц, ссылающиеся домены и рейтинг по отзывам.
- Аналитика сайта: трафик, видимость, запросы, сравнение выдачи, конкуренты, заявки и продажи, показы и CTR, индексация, пользовательский опыт и технические ошибки.
- Аналитика бренда: спрос, контрольные ответы ИИ, отзывы и локальная карточка, внешние ссылки. Таблицы и исходные примеры доступны для самостоятельной оценки; фильтры выделяют потерянные упоминания и отзывы с низкими оценками.
- У отчётов указаны период, условный источник и охват. Для Core Web Vitals отдельно указано окно в 28 дней; история прошлого года и переходы из ИИ отсутствуют и не изображаются нулём.
- Помощник находится только в сводке. Кнопка разбора в отчёте переводит туда с выбранной темой.
- Разборы сохраняются в общем диалоге; план исправления можно согласовать или отклонить.
- Комплексный анализ возвращает три карточки конкретных действий с оценкой «≈ +…%» рядом с каждой и названием метрики. Это иллюстративные сценарии, а не прогноз: основания, база сравнения и условия раскрываются внутри карточки, эффекты не суммируются. Для исправления noindex доступен существующий план согласования; карточки сохраняются в истории диалога.
- В разделе «Решения на согласовании» согласованное решение можно отдельно отметить как реализованное. Отметка с датой видна в сводке, технических отчётах и карточке решения; её можно снять. Статус сохраняется в браузере, «Начать заново» сбрасывает его. Это отметка пользователя в демо, а не автоматическое изменение или проверка настоящего сайта.
- Показатели в сводке имеют стрелку направления и изменение со знаком. Красный означает ухудшение, зелёный — улучшение; для доли проблемных страниц рост считается ухудшением. Нулевое изменение и отсутствующие данные нейтральны. Исторические метрики не меняются при отметке реализации.
- Основные числа в сводке — проценты: относительное изменение трафика, заявок, спроса и доменов либо текущая доля запросов, ответов и проблемных страниц. Изменение долей показано в процентных пунктах. Абсолютные значения вынесены в мелкую справочную строку; рейтинг сохранён в шкале из 5. Положительные примеры: спрос на бренд 1 000 → 1 100 (+10%) и домены 24 → 25 (+4,17%).
- Все данные вымышлены. Работа ИИ имитируется в браузере, внешние LLM и API не подключены.

`reports.js` содержит подготовленные данные и представления дополнительных отчётов. Общий сценарий согласован с исходным: 10 000 → 7 200 визитов, 200 → 144 заявки при конверсии 2%; все потери относятся к одной группе из 12 страниц. Присутствие в ИИ измеряется только на 20 условных ответах, рейтинг — на одной условной площадке. Источники в интерфейсе не означают подключение реальных сервисов.

Для локального просмотра откройте `index.html`. Установка зависимостей и сборка не требуются.

Публикация: GitHub Pages из корня ветки `main`. Изменения сайта публикуются после push в `main`.
